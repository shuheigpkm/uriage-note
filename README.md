# 売上アップ・ノート

宮崎料理の居酒屋向けに作った、スマホで使う記録ノートです。

- 会話メモ：お見送りのあとに、聞けたことをタップで残す
- お客様台帳：名前を忘れても、見た目の特徴や会社名で探せる。名刺の写真も残せる
- 売上の分析：日販・客数・客単価・曜日別・FL比率
- 施策の検証：施策ごとに目標を決め、日々の記録から効果を自動で計算

## データの保存先

記録はすべて、使っている端末のブラウザの中にだけ保存されます。サーバーには送られません。
一度開けば、ネットにつながっていなくても起動します。

## 使い方

https://shuheigpkm.github.io/uriage-note/ をスマホで開き、「ホーム画面に追加」します。
